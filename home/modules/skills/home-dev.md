# Разработка проектов

Доводи задачу до проверенного результата. Инструкции и требования текущего проекта имеют приоритет над общими рекомендациями этого скила. Для изменений Nix-конфигурации дополнительно используй скил `nix`.

## Рабочий процесс

1. Изучи относящиеся к задаче инструкции, требования, код и тесты. Проверь состояние Git и сохрани чужие изменения.
2. Определи ожидаемое поведение и сделай минимальную правку в принятом стиле, без побочных рефакторингов. Учитывай влияние на данные, совместимость и безопасность там, где это существенно.
3. При изменении поведения добавь полезный тест; при исправлении ошибки — регрессионный. Запусти релевантные проверки проекта и разберись с их сбоями.
4. Просмотри итоговый diff: в нём не должно быть секретов, личных данных и случайных файлов. Сообщи, что изменено, что проверено и что осталось непроверенным. Не коммить и не публикуй без запроса или явного правила проекта.
